# Look 01 LUT (teal-orange cinematic grade)

Put `Look01_TealOrange_Master_SLog3_65.cube` here (and optionally the 33-point version) to enable
"Look 01 teal-orange" in the Style panel. The LUT is by @shakirc.ai and comes from the
teal-orange-cinematic-grade skill; it is NOT committed to the repository (see .gitignore) because it is
someone else's work. It expects Sony S-Log3 / S-Gamut3.Cine footage; on ordinary phone video the colours will
be wrong; use the "Cinematic" grade instead.
